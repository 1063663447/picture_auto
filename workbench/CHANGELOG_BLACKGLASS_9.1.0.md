# BLACK GLASS 9.1.0 · 需求调整与回归记录

日期：2026-11-06。正式首页资源版本为 `9.1.0`，继续使用 `http://127.0.0.1:8787/`。本次按用户六项反馈调整，不改 README；以下是当前规则，9.0.0 文档中的计价／默认接口描述仅作历史记录。

## 六项修改

1. **主备接口**：配置默认接口改为 a6api，65535 保留为备用。网页只显示“主接口”“备用接口”，正常生成和返工共用命名及排序；内部 provider ID 保留以兼容历史任务。旧浏览器存储通过一次性迁移切换主接口，之后用户仍可手动选择备用接口，不进行失败后的自动付费重发。
2. **主接口固定计价**：配置 `providers.a6api.fixed_unit_price=0.038`，优先级高于按模型价格、飞书价目和尺寸档位。网页预估、模型列表（含旧缓存重新计价）、harness 报价、任务预估、配额判断和新用量记录均使用工作台设置。备用接口延续原价目；不重算历史账本。没有在 README 中加入这项价格规则。
3. **滚动优化并保留动效**：64 个运动粒子、平面微光、边缘高光、点击涟漪、显影翻面与毛玻璃均保留。固定面板几何与移动卡片分开缓存；滚动只更新 scroll offset 并合并到绘制帧，不在每次事件扫描全画廊或重测固定面板；可见运行卡片几何最多读取 8 张。显影读取合并到 4 个涟漪槽位；相同尺寸不重复重置 WebGL 缓冲区。玻璃移到固定伪元素背板，滚动区隔离绘制；离屏跳过移到尺寸确定的图片区域，避免卡片估计高度带来的跳动。
4. **项目总耗时**：`Job.finished_at` 和 `duration` 由后端保存，完成后显示“总耗时 …”。从服务端创建项目算到任务结束，包含排队、生图、打包，不叠加每张耗时；后续下载、写日志／同步不会使结束时间持续增长。重试重新进入运行态时清空结束时间，最终累计到该项目最新结束。旧任务读取时按已有 created_at／updated_at 兼容回填，不批量改写历史文件。
5. **需求分流**：点击生成时 trim 后为空，直接按默认生图；非空自动打开 harness 并发送需求，先对话对齐、提炼约束，再由“按分析结果生成”或对话中的明确确认提交。不会把非空原话直接绕过 harness 发给生图模型。保留“忽略需求，按默认生成”显式入口。分析、直接生成、返工和重试继续共享互斥。
6. **只有衣服的优先级**：修复普通／返工 harness 未传递画面主体的漏项；harness 上下文、工具提交、前端确认提交和 runner 请求边界均保留显式选择。garment 是输出约束：即使原图、效果图、基准图、颜色参考图含人物／模特／假人，也必须去除载体，只转移服装版型／工艺／颜色／印花，不转移人体。提示词清理已知“保留人物／姿态／不可动非衣服像素”等冲突片段，并把禁人物放到最前；person 和 auto 保持原有语义。

## 文件

- `config.json`：默认接口、可见名称、主接口固定价；未改密钥或 provider ID。
- `skillbridge/pricing.py`、`service.py`：接口级固定价优先、模型缓存重新报价、配额与账本衔接。
- `skillbridge/job.py`：项目结束时间与耗时的序列化／兼容读取。
- `skillbridge/api.py`、`agent.py`：主体和质量／尺寸／参考图策略透传、报价接口选择、重复工具提交互斥；任务已创建后对话异常仍返回 job ID，不再次降级开工。
- `skillbridge/prompts.py`、`runner.py`：禁人物优先规则、引用图人物隔离和发送前再次执行主体规则；不修改参考图片，不新增收费重试。
- `web/app.js`、`index.html`、`blackglass-ui.js`：默认接口迁移、固定价展示、空／非空需求分流、完成耗时及 9.1.0 缓存版本。
- `web/blackglass/effects.js`、`glass.css`：几何缓存、滚动批处理、显影读取批处理、绘制隔离；新增轻量 `PrismFX.stats().geometry` 计数供验证。
- `tools/check_primary_workflow.py`、`check_garment_priority.py`：固定计价、耗时、harness 主体／设置及引用图人物约束回归。
- `tools/check_blackglass_browser.js`、`check_blackglass_scroll.js`：正式源码在一次性 iframe 中的交互与滚动夹具。
- `tools/check_effect_ref.py`、`check_shape_lock.py`：旧的完整常量断言升级为当前输出主体适用的完整角色段落，并增加禁人物优先检查；保留双图顺序、基准派生拓扑、fidelity、工艺／印花及数量断言。
- `HANDOVER.md`：指向本版本；README 保持本轮开始时的内容不变。

## 验证边界与启用

- 所有新增自动测试使用临时文件或隔离数据，阻断外部 HTTP；未发送飞书消息／通知，未新增付费生图调用。隔离服务关闭飞书同步、通知和闸门，正式配置中保留原有业务设置。

- 不更改历史任务、账本、密钥、skill 规范原文和参考图片；既有工作树修改保留。回退时按文件审阅恢复，不使用 `git reset --hard`。
