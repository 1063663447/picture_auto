# 9.3.0 · 模特一致性修复与内部一键便携包

日期：2026-11-06。网页资源版本：9.3.0。正式主题和已有业务继续沿用 9.2.0。

## 本轮改动

### 原图人物在各颜色、派生和返工中保持一致

用户原图有人物时，不能因为颜色参考或款式效果图是平铺衣服，就把人物一起移除。本轮将原人物保留设为人物任务的最高优先级，锁住人物身份、面部、头发、肤色、手、姿态、人物数量与原场景。当前衣服仍按选择的款式和颜色重绘。

- 在普通生图、同款基准色派生、只改色、两阶段处理以及最终请求边界统一应用人物正向与负向约束，清理与之冲突的旧禁人／空衣服文字。
- 区分用户选择 `subject_choice` 与批次汇总 `subject`，保存每个任务的主体决策。混合原图批次在重新载入和重试时不再被整批覆盖。
- 自动返工继承原始任务和返工来源链上的主体决策，读取真正的原始上传图；不能依据已经错误丢失人物的当前成品重新判定主体。
- 人物派生在接口图片数量允许时保留原始人物图作为第三张参考；连续返工使用现有原图追溯机制。
- 用户明确选择“只有衣服”或“保留模特”仍优先。原图无人时不凭空造人；缺失或存在歧义的老任务来源不虚构人物身份。

涉及 `skillbridge/prompts.py`、`runner.py`、`service.py`、`subject.py`，新增 `tools/check_person_consistency.py`。

### 移除三处显示文案

正式网页已移除 `GRAPHITE / SILVER VIOLET`、`石墨银紫创作工作台` 和 `按工作台设置计价`。保留主黑副紫主题、粒子、毛玻璃、真实价格与用量功能。首页资源统一递增为 9.3.0，避免继续使用旧缓存。

## 便携包使用

交付文件：`releases/PictureWorkbench-9.3.0-win-x64-internal.zip`，对应校验文件为同名 `.sha256`。

1. 同事将整个 ZIP 完整解压到可写目录，支持中文和空格；建议使用较短目录，例如 `D:\生图工作台`。
2. 双击根目录的 **一键启动.bat**。六步检查后服务自动启动、浏览器自动打开并完成本机登录，无需填写 API。
3. 保持启动窗口打开；关闭窗口停止服务。再次双击会复用本目录已运行的服务，端口被其他程序占用时自动选可用端口。

适用：Windows 10/11、64 位 Intel/AMD、PowerShell 5.1。普通用户权限即可。其他系统及 Windows ARM 未验证；没有在同事实体电脑或全新虚拟机上实测。

包内包含 Python 3.12.10、20 项固定版本依赖、所需微软运行库 DLL、Three.js 0.160.1、完整网页、skill、13 款及 49 张官方效果图、定价、主备接口、AI、飞书与相关现有内部配置。API 配置按用户授权内置，不输出明文密钥。

不需要预装 Python、Node.js、npm 或 Three.js。正常启动直接使用包内环境；完整环境准备不需要下载。校验发现文件缺失／损坏时，先从离线缓存恢复；缓存也缺失时才从华为云／阿里云国内 HTTPS 镜像下载，显示百分比并做 SHA256 校验。图片 API 和在线 AI 使用时仍需网络。

- `一键检查修复.bat`：修复后退出，不启动服务。
- `logs/`：启动与环境检查日志。
- `workbench/data/`：每台电脑独立保存图片、任务、用量和本机登录配置。不带原电脑历史任务、账本、测试数据或沙箱。
- 修复不覆盖已经存在的 `.env` 和 `config.json`。每台机器的访问令牌与会话配置自动生成，包内路径按解压位置重建，不改系统 PATH。
- 前置检查不实例化 Workbench、不读取任务、不访问飞书或外部接口；正式服务取得单实例锁后才载入业务状态。重复启动不会改写运行中任务。
- 本机健康请求绕过代理。修复使用较短临时目录，避免深层中文目录的解压中间路径超长。

新增 `portable/start.bat`、`bootstrap.ps1`、`launch.py`、`requirements-bootstrap.txt`，构建入口 `tools/build_internal_portable.py`，验证入口 `tools/check_portable_package.py`。
