fix(prompt): 纯衣服原图不再被生成出人物（主体判定 + 禁人硬约束 + 成品复查）

现象：客户原图是平铺的单件衣服（没有真人），同一批里 3 张平铺有 1 张变成
「女生穿着这件衣服在卖」（深酒红那张），另外 2 张还是平铺。

根因：提示词在**邀请**模型造人。
1. SKILL.md 的改款换色模板写死 `Keep the exact same person, face, hair, skin, hands, jewelry,
   watch, pose, body proportions, pants, background …` —— 平铺图读到这句就是在被要求造一个人；
2. prompts.PRESERVE_CLAUSE / KEEP_ITEMS["person"] 同样写死「the same person, face, hair, skin」；
3. refine.REWORK_TEMPLATE 的改图模板也是同一句，所以改图还会再补一次人。

修复（三层）
1. 中性主体句（默认，两种原图都成立）：`SUBJECT — the source image alone decides what the
   subject is`：原图有模特就保持同一个人，原图是空衣服就保持空衣服，谁都不许新增原图没有的
   人和身体部位。SKILL.md / PRESERVE_CLAUSE / KEEP_ITEMS / 改图模板 / 换色模板 / 改款模板
   全部改成这套说法，不再出现「保持同一个人」的绝对句。
2. 禁人硬约束（判定为纯衣服时）：NO_PERSON_CLAUSE —— 只能有这件衣服，领口露背景或领内暗部、
   袖筒衣身是空的、不许有模特/脸/脖子/手/皮肤/身体；否定词追加 20 余条
   （no person / no human / no face / no hair / no neck / no skin / no one wearing the garment …）。
3. 成品复查：出图后用原图背景做遮罩，若「原背景区域」变成大片皮肤色 → 任务记 person_alert
   并写日志；retry_on_person=true 时追加 NO_PERSON_REINFORCE 自动重画一次（默认关，不偷偷多花钱）。

主体判定（skillbridge/subject.py，纯 Pillow，无 numpy）
- 只用「皮肤证据缺席」这一个可靠方向：皮肤占比 ≈ 0 才断言纯衣服；
  有皮肤一律按真人/不确定走中性提示词 —— 宁可少禁，也绝不把模特图的人擦掉。
- 深酒红/正红色相在 350~5°，不在皮肤色相区间，不会被误当皮肤。
- 可强制：job 参数 / 表单 / 界面「生成设置 → 画面主体」（自动 / 只有衣服 / 真人上身）。
- 改图继承源任务的 subject，平铺图返工不会再补人。
