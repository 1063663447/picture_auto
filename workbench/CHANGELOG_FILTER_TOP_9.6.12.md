# 9.6.12 · 筛选行也置顶 + 统计去重（成品区再让出约 30px）

客户要求：

```
全部 14 · 已完成 7 · 生成中 0 · 待处理 7 · 异常 0   紧凑
```

这行也置顶，并且去重。

## 改法

以前有两处重复的统计：

| 位置 | 内容 |
| --- | --- |
| 顶栏 KPI（9.6.11 挪上去的） | 总任务 / 已完成 / 失败 / 花费 |
| 成品区上方筛选行 | 全部 / 已完成 / 生成中 / 待处理 / 异常 + 紧凑 |

`全部 = 总任务`、`已完成 = 已完成`、`异常 = 失败` —— 三对数字完全重复。

现在**只留一处**，全部收进顶栏同一行：

```
● 服务已连接   0 张原图 · 3 款 · 0 张预计成品        全部 14  已完成 7  生成中 0  待处理 7  异常 0   [紧凑]  │ 花费 ¥0.266/0.532
```

- 删除 `#kpiTotal / #kpiDone / #kpiFailed`（连同它们的 `animateNumber` 调用），
  数字由筛选行承担（`applyFilter()` 本来就会按 `job.tasks` 重算这些数）。
- 花费保留成一个小 chip（它不重复），带竖线分隔。
- 「紧凑」按钮跟着筛选行一起上顶栏。
- 成品区里那行筛选整块删掉，`#galleryPane` 从「进度条」开始。

窄屏：≤900px 隐藏筛选数字、只留文字；≤760px 进一步压缩间距（标签文字保留，仍可点）。

## 验证

- `check_web_static / check_blackglass_static / check_ui_slim / check_master_chat` 全绿
  （`check_blackglass_static` 会检查 index.html 里是否还缺 app.js 引用的 id，
  所以删掉 `kpiTotal` 等三个数字后必须同步删掉 JS 里的调用——已处理）。
- 筛选计数仍由 `blackglass-ui.js#applyFilter()` 写回 `[data-filter] span`，位置移动不影响。

前端资源版本 `?v=9.6.23`。
