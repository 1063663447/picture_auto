# 星雾 PRISM · 三套深色色调沙箱

推荐先双击 [tones.html](tones.html) 比较黑曜紫、墨蓝银、烟晶酒红三套色调，再打开完整工作台。色板、独立入口和动效说明见 [PALETTES.md](PALETTES.md)。也可直接双击 `index.html`；不需要启动服务、安装依赖或填写生图密钥。请保留本目录与 `../../library/` 的相对位置。

这份独立演示基于当前正式 `workbench/web/index.html`、`app.js`、`style.css`、`aurora.css` 延续优化。本轮未编辑正式前台。`baseline.html` 为原布局对照，主要用于视觉比较。

## 当前视觉与交互

- **三套完整主题**：黑曜紫、墨蓝银、烟晶酒红各有完整的面板、按钮、闪卡和弹窗配色。工作台顶部可直接切换，保留当前任务与款色状态；真实服装图片与色卡按原始颜色显示。
- **文字层次**：标题、正文、辅助说明分别设置字号、字重及亮度，保留清晰灰白文字。
- **Three.js 平面光效**：一个本地 WebGL 画布，保留原有流光、边缘高光与点击反馈，并新增实例化星光、浮游粒子和细雨。三类效果可独立开关、叠加、调节强度或暂停，图片区域降低叠层亮度；没有三维场景。
- **生成闪卡**：提交即铺好卡背；排队、生成、失败和取消均有状态。图片解码后，以平面收窄、换面、展开的两阶段动画展示正面；离屏卡片按需读取图片，可见卡片才播放生成反馈。
- **完整大图**：弹窗采用标题、可伸缩图片区、下载栏三行布局，图片完整适应可用区域，避免下方被裁切。保留上一张、下一张、方向键和下载。
- **生成设定**：独立描边、深紫底、图标、摘要及明确的“调整参数”动作；展开为控制台内部浮层。
- **个人菜单**：桌面点击左下角头像，从头像旁弹出飞书历史、用量与花费、账号及退出会话。点击后进入对应右侧栏。管理后台独立保留。手机通过“配置 / 画布”右侧的头像打开同一菜单；支持 Esc、方向键与焦点返回。
- **布局与性能**：桌面两侧采用同顶同底的可见外框，款式列表与画廊独立滚动，生成按钮固定在画布底部。背景、主面板、款式卡和输入区分别设定明暗层级；切换色卡只更新对应款式，同一任务复用图片卡节点，未变化的轮询跳过卡片属性写入。

## 建议体验

1. 初始载入 **2 张素材 × 6 款 × 3 色，共 36 张**样图。可换款、选色、添加和移除款式，查看数量与费用同步。
2. 点“生成 36 张”，观察卡背等待、逐张翻面、完成图提前查看和取消反馈。
3. 顶部可选四个场景：批量出图、慢速回传、异常与重试、120 张压力。
4. 异常场景有 1 张限流和 1 张超时；支持只重试限流、单张重试、批量重试失败项，保留其他成品。
5. 选择成品，体验需求沟通、流式工具反馈、换接口/模型返工和 ZIP 导出。
6. 点击头像查看个人菜单；点击醒目的生成设定修改模型、主体、比例、分辨率和质量。

压力场景为 **5 张素材 × 8 款 × 3 色，共 120 张**。所有生成与排队时长均为演示。

## 模拟边界和头像

所有 `/api/` 调用由 `mock.js` 在浏览器内接管，不发往真实工作台、供应商或飞书。上传只保留在当前页面；支持 PNG/JPEG/WebP，单张 20 MB，先生成小预览，移除时释放 URL。

结果为款式库已有样图，**不会真的按上传图换款、换色或返工**。ZIP 是有效压缩包，包含演示预览、说明和任务清单。报价、用量、历史、流式分析及账号均为模拟；管理入口不写入正式配置。

已按用户要求调用 `pi-desktop/imagegen` 的 `GenerateImages` 工具生成 1 张头像，工具返回 `IMAGE_NOT_CONFIGURED`，没有生成成功。当前使用本地 SVG 占位。请先在“设置 → Models → Image generation model”配置专用生图模型；最新紫黑头像提示词和失败原因保存在 `AVATAR.md`，未自动重试。

页面刷新后重建模拟任务。设置使用独立 `aurora.flow.sandbox.*` 前缀，对照页使用 `aurora.flow.baseline.*`。

## 文件与依赖

- `index.html`、`app.js`：当前首页的沙箱副本和主要功能逻辑，保留正式首页全部原有 ID。
- `base.css`、`aurora.css`：正式样式快照。
- `flow.css`、`flow.js`：有边界的工作区布局、筛选和渐进加载。
- `tones.html`、`toneboard.css`、`toneboard.js`：三套色调总览、界面示意与完整预览。
- `tone-01-obsidian.html`、`tone-02-nocturne.html`、`tone-03-garnet.html`：三套版本独立入口。
- `themes.css`、`themes.js`：完整主题配色、色调控制与氛围设置；`atmosphere.js`：星点、粒子和雨丝的批量渲染。
- `prism.css`：排版、组件层次与字号；`noir.css`：对齐框架与深色层次基础，最终三套配色由 `themes.css` 覆盖。
- `prism-motion.css`、`prism-ui.js`：闪卡、完整灯箱、头像菜单与动画时序。
- `prism-fx.js`：Three.js 平面着色器、交互反馈、后台暂停、尺寸及像素比控制。
- `vendor/three-0.160.1.min.js`、`vendor/THREE-LICENSE.txt`：本地 Three.js 与 MIT 许可。使用可直接由本地 HTML 加载的构建，运行时不依赖 CDN。
- `mock.js`：队列、生成、重试、返工、历史、账号和 ZIP 模拟。
- `catalog.js`、`previews/`：当前 10 款、49 色的轻量预览，总计约 533 KiB。
- `download-data.js`：点击导出后才加载的样图数据。
- `AVATAR.md`：头像工具调用状态与待用提示词。
- `VALIDATION.md`：功能、布局和性能检查记录。

正式接入仍需对齐真实任务 ID、缩略图接口、原图下载地址和供应商状态。真实生图、飞书与大尺寸成品性能不在本地模拟验证范围内。
