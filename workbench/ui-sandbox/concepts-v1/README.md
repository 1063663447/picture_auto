# 星雾画布 · 独立 UI 原型

当前主方案为 **AURA × ATELIER 星雾画布**：保留星雾紫的配色、左侧控制区和玻璃层次，融合香槟版的叠照画布、色彩影集、并排看图与大图浏览。

## 打开

直接用 Chrome 或 Edge 打开 [03-aura-atelier.html](03-aura-atelier.html)，无需启动工作台或安装依赖。

[方案总览](index.html) 保留 [星雾紫基础版](01-aurora.html) 和 [香槟白基础版](02-atelier.html) 供对照。翡翠鎏金已淘汰，不再保留入口。

样图通过相对路径引用 `../../library/refs/`。如需复制到其他位置，请保持这一目录关系；本页 CSS 与 JS 均内嵌，不依赖外部资源。

## 可以体验

- 点击或拖入 PNG / JPG / WebP，替换左侧和主画布的原图预览；支持 20 MB 内图片。
- 切换服装款式、选色；点击影集中的色卡更换主画布样图。
- 切换「叠照 / 并排」，或双击色卡、点击主图打开大图。
- 大图支持「单张 / 并排」、左右方向键切色、Esc 关闭，以及下载当前本地图片。
- 收藏当前颜色，通过「只看收藏」筛选影集。
- 左侧与画布下方的创作需求同步；点击快捷词可继续补充。
- 点击「模拟生成」查看约 6 秒的进度演示，可随时取消。

## 原型边界

上传、选择、收藏和日志仅保存在当前页面内存，刷新会重置。模拟生成展示本地参考图片，不执行真实 AI 生图、换色、计费或上传。比例、模型、质感等设置只用于预览交互。

本目录用于验收视觉与交互；接入正式前台需要另行确认。系统启用「减少动态效果」时，装饰动画会停用。
