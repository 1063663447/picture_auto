# 主黑副紫 · 五套沙箱 demo

入口：`http://127.0.0.1:18793/black-purple-v3/`。

| 编号 | 方案 | 方向 | 独立页面 |
|---|---|---|---|
| 01 | 碳黑哑光 | 中性炭黑，极细低饱和紫线，最克制 | `01-carbon.html` |
| 02 | 黑曜烟玻璃 | 黑色烟玻璃，雾紫边缘反光，保留通透 | `02-smoke.html` |
| 03 | 石墨银紫 | 石墨黑灰，冷银紫边界，信息层次清楚 | `03-graphite.html` |
| 04 | 暖墨葡萄紫 | 暖墨黑，暗葡萄紫，柔和偏服装质感 | `04-plum.html` |
| 05 | 曜黑电紫 | 曜黑大底，选中态／进度／按钮边缘电紫 | `05-ultraviolet.html` |

- 五套统一使用纯黑页面背景；主面板、展开款式、生成设定、需求框、闪卡背面和按钮均改为黑灰基底，紫色不再大面积铺底。
- 总览页提供五套小型界面对比、同一工作台即时切换、桌面／手机尺寸预览、暂停微光与独立打开。切换不重建当前模拟任务。
- 完整页面复用 `../flow-v2/` 的原生沙箱交互及本地图片，通过 `base` 保持路径一致；不加载旧 `themes.js`，不写正式主题偏好。
- 保留毛玻璃、64 个运动粒子、平面微光和显影翻面；五套均为相同内容与动效，便于比较。概念卡片黑紫比例为视觉意向，不是页面像素测量。
- 演示生成、模型、报价、账号、导出均使用现有沙箱 mock。此端口只提供静态文件，不能调用正式后端或付费生图。
- 正式 `web/`、`skillbridge/`、配置、账本、README/HANDOVER 均未修改。旧沙箱与历史原型保留。

关闭预览服务后可重新启动：

```powershell
cd E:\picture_auto
python -m http.server 18793 --bind 127.0.0.1 --directory workbench/ui-sandbox
```

浏览器打开上述入口。不要以 `file://` 方式直接打开，因为对比页使用同源 iframe 消息与本地模拟请求。
