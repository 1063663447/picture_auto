## 二、对话优先：生成后直接进对话框，AI 返图给用户确认

流程改成：

```
放原图 + 选款式 → 点「开始生成」
   → 柜台自动拉出对话框（master 模式），对话里显示「基准图生成中…」
   → 基准图出来：AI 把图**返到对话里**（可点开看大图）
        按钮：「就按这张改色」 / 「我要改…」
   → 说「领口小一点」→ AI 生成改图任务 → 出图后**再返图** + 「用这张当基准，开始改色」
   → 反复到用户满意 → 确认 → 其余颜色按这张基准改色（进度也在对话里更新）
```

- 新增 `startMasterChat` / `masterWatch` / `chatMasterCard` / `startReworkWatch` / `chatReworkCard`
- 生成成功后（`createJob`）只要这条任务开了基准闸门，就自动 `startMasterChat(job.id)`
- 对话里改图任务返回时**不再算「已提交」**（以前会把输入框锁死），而是盯这条改图任务、
  出图后返图并给「采纳当基准」按钮（`approve` 带 `adopt`）
- 关掉对话或切走就停轮询（`stopMasterWatch` / `stopReworkWatch`），不会后台空转
- 原生的基准图审核条保留（画布顶部），两条路都能确认

## 四、主动沉淀（自学习，不用用户说「记住」）

- `service.approve_master` 确认时**自动**调 `learn_from_review`：
  把这次对齐过的要求（对话里说过的每次修改 + 确认备注）写进该款式 `library/prompts/<slug>.json` 的 `lessons`
- 开关 `defaults.auto_learn`（默认 `true`）；任务日志会写「已自动记进款式规则 N 条：…」
- 前端确认后提示「这次的 N 条要求我已记进这个款式的规则，下次同款直接用」
- agent 系统提示改为「沉淀是默认行为，不用问用户要不要记」；`save_style_rule` 只用于补记/显式要求
- 重复的对齐要求不新增，只累加命中次数；每次注入最多 6 条
