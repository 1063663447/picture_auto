# 9.6.5 · 基准图固定白色优先 + 出一张就能确认（单张）+ 确认回到画布

日期：2026-11-11。后端 + 前端改动，**需重启服务**；前端资源 `?v=9.6.11`（Ctrl+F5）。

客户要求（原话）：

> 以后基准图统一先做白色，并且确认页要说明哪个图是哪个款式。并且先生成出来的可以先确认和修改
> 不需要等全部完成后才同步。取消基准图刚生成就立马调ai窗口的逻辑（即保留如图模式，但需要能够
> 支持针对单张基准图做改图而不是全部对齐），改为原本的在系统前端确认，需要改图时再调窗口对话和
> 进行后续的对齐需要以及记忆写入。

## 一、基准图固定先做白色

`runner.plan()` 里基准色改成**白色优先**（`_master_index`）：
`white / off-white / ivory / cream`，或色号以 `WH` 开头、中文名「白色/米白」；
没有白色才退回该款第一个颜色。任务日志会写清这次用哪个色做基准。

顺手修掉一个连带 bug：白色不在第一位时，排在它前面的颜色拿不到 `master_task`
（因为 master id 原来是在循环里赋值）——现在循环前就把 master id 算准。

## 二、出一张就能确认（按张放行）

- **不再等全部基准跑完**：任意一张基准图出图后立刻把任务切到 `review`，
  画布上的审核条立刻出现这张，可以马上确认或提修改；其它基准还在生成也没关系。
- **确认是按张的**：`approve_master(task_ids=[这张])` 只放行这一张的派生色；
  没确认的基准，它管的派生色一张都不动（日志写「还有 N 张派生色所属的基准图没确认」）。
- 派生跑完但还有基准没确认 → 任务**回到 review** 继续等（不打包、不结束）；
  全部确认且派生都跑完才正常收尾。
- `review_mode` 与 `review_gate` 分开：前者表示「这批开过审核」（派生阶段也认它做过滤），
  后者表示「这一趟只跑基准」。

## 三、确认页标清「哪个图是哪个款式」

审核条里每张基准图变成一张卡片：

```
[缩略图]
23 索罗娜短袖          ← 款式名（garment_name）
白色 · 待确认           ← 颜色 + 状态
[这张可以] [改这张]      ← 单张确认 / 单张改图
```

已确认的卡片变绿、按钮收起；底部按钮变成「全部确认，按它们改色 / 确认剩下 N 张」，
进度文案也会写「还有 N 张待确认（已确认 M 张）」。

## 四、取消「生成即弹 AI 窗口」

- `createJob` 成功后**不再自动打开对话框**（删掉 `startMasterChat` / `masterWatch` / `chatMasterCard`）；
- 确认回到**系统前端**（画布审核条），「确定」和「改这张」都在这里点；
- 只有点某张的「改这张」时才打开对话框，而且**只针对这一张**：

```
现在只改「23 索罗娜短袖 · 白色」这一张基准图，其它颜色先不动。
直接说要改哪里就行（比如「领口再小一点」「印花别动」），我改完把新图发给你看；
觉得可以了就回工作台点这张的「这张可以」，那时才会开始按它改色。
```

- 对话里的快捷话术也改成「改哪里」口径（领口/颜色/印花/裁切/以后都这样），
  不再出现「就按这张改色」这种确认话术；
- 改图任务出图后仍在对话里返图 + 「用这张当基准」（采纳），走的是同一条 `approve` 接口；
- 对齐要求的记忆写入照旧：确认后后台静默评估（9.6.3 的逻辑），只是入口换回画布。

## 五、验证

```powershell
python tools/check_master_partial.py --show   # 本次新增：白色优先 + 出一张即可确认 + 按张放行
python tools/check_master_chat.py             # 确认回到画布 / 不再自动弹窗 / 单张改图
python tools/check_master_gate.py             # 闸门全链路
python tools/check_silent_distill.py          # 静默评估沉淀
python tools/check_auto_learn.py
```

`check_master_partial.py` 钉的是：
1. 颜色顺序故意写成 `black, white, red` → 基准仍必须是**白色**，黑/红都是派生；
2. 只跑那张白色基准 → 任务立刻 `review`、可确认、派生一张没跑；
3. 确认白色 → 它管的黑/红派生都跑；两个款式的场景里，只确认 A 时任务仍停在 review，
   确认 B 之后才正常收尾。

界面验收（mock 接口，不花钱）：画布审核条显示「23 索罗娜短袖 / 白色 · 待确认」+
「这张可以 / 改这张」，点「改这张」才弹对话框且开场白点名只改这一张 —— 已截图确认。

## 六、已知限制

- 「白色优先」只影响基准色选择；如果某款没有白色，仍用第一个颜色做基准。
- 按张确认下，同一批的派生色分批出图：先确认的那张，它的派生色会先出，其余等确认。
- 一键「全部确认」仍保留（一次确认所有已出图的基准），适合信任基准图的老手。
