# 9.4.5 · 款式转换段 + 负面约束真正生效（卫衣改长袖 T 恤，袖口终于是平口）

日期：2026-11-10。后端改动，需重启服务；前端资源版本不变。

## 现象（运营给的例子）

原图是一张圣诞 promo 图，小孩穿**红色圆领卫衣**（明显罗纹袖口、罗纹下摆）。
要求改成 **25 长袖童装（平口）**，出图只把颜色换成了宝蓝 —— 袖口还是卫衣的罗纹收口，
下摆还是有罗纹带。同一批里有的对、有的错。

## 查出两个真问题

### 1) 负面约束根本没发给模型（影响所有不支持 negative 字段的接口）

`65535 网关（terra）`、`a6api`、`fal` 这些接口**没有 negative_prompt 字段**，
而 `runner` 只是把 `request.negative` 传下去，adapter 里 `supports_negative=False` 就**整段丢掉**。
也就是说：那 3~4KB 否定词（"Do not add ribbed cuffs"、"no hood"、"不要重画图案"…）
**从来没到过模型手里**。skill 原文其实写了"若模型不支持负面提示词，将其合并到主提示词末尾"，
但代码没做。

修：请求边界（`runner._guarded_call`）判断接口能力，不支持的就把 negative
用 `prompts.with_negative()` 合并到提示词末尾，并把 `negative` 字段清空（避免重复/无效字段）。
支持 negative 的接口（custom_json 等）行为不变。

### 2) 「换款式」这件事在提示词里没说清楚

只写"保持别动 + 目标款式"时，模型会把源图的**结构**照搬（卫衣→还是卫衣，只换色）。
实测三种写法后定了现在的方案：

- 新增 **款式转换段 `CONVERT THE GARMENT TYPE`**（`prompts.convert_clause()`），写在提示词靠前位置，
  按目标款式的袖口工艺给不同规则：
  - 平口款（T 恤系）：**"如果源图有罗纹袖口 / 松紧收口 / 罗纹下摆，全部去掉，改成同布平折边；
    袖筒直通那个折边"**，并写明面料是薄针织而不是抓绒；
  - 罗纹款（卫衣系）：反过来要求补上真正的 1x1 罗纹带；
  - 同时列出该款式**不许出现的部件**（非卫衣 → no hood / no drawstrings / no kangaroo pocket…）。
- 一次到位、两段式第一阶段、以及**改图**都注入这段（改图只有一张参考图，所以用
  `reference_image=False` 的版本，不提 "IMAGE 2"）。
- 「改图」里识别改款意图：`classify_requirement` 新增 `garment_change`
  （长袖/短袖/卫衣/连帽/圆领/罗纹/平口/袖口…），命中就把 "keep the same garment type, cut, seams,
  ribbing, cuffs, hem" 这条从 KEEP 列表里撤掉 —— 否则改图提示词会亲手要求"保留罗纹袖口"。
- 改图沿用上一轮提示词当 context 时，先把里面的图片角色段落、"去掉人物"段落清掉
  （`refine._sanitize_brief`），避免出现"保留同一个人"和"REMOVE the original wearer"同时存在。

## 验证（真机，a6api / gpt-image-2.5-sunburst，¥0.038×3）

同一张圣诞 promo 图，目标 25 长袖童装 · 宝蓝：

| 版本 | 结果 |
|---|---|
| 修之前（线上原样） | 卫衣，罗纹袖口 + 罗纹下摆（客户投诉的那张） |
| 只加款式锁/去罗纹文字 | 还是卫衣（说明光靠文字不够） |
| 加了转换段 + 合并负面词（当前） | **薄针织长袖 T 恤**：袖子直下、平折边、直下摆、无罗纹带 |

对比图：`data/test/kid-cuff/compare-3.png`（源图 / 修前 / 修后）、
`V1-effect-first.png`、`V2-convert-block.png`、`V3-generic.png`（三种写法的对照）。

回归（14 个离线脚本全绿）：

- 新增 `tools/check_request_boundary.py`：不支持 negative 的接口必须把否定词并进提示词、
  negative 字段要清空；支持的接口行为不变。
- `tools/check_cuff.py` 增加：13 个款式的提示词都含转换段；平口款必须写"去掉罗纹收口→平折边"，
  罗纹款必须反过来要求补罗纹带。

## 部署与提示

- 重启服务后新单生效；**已有错误成品不会被自动重画**，需要的话在成品上点「改图」重跑。
- 提示词因此变长（~13.5KB/张）。条款还会继续精简，但转换段和负面词合并这两件事是必须的。
- 如果某次仍然画成卫衣：把「画面主体」保持 auto/person 不动，改用改图并写明
  「改成平口长袖 T 恤，去掉罗纹袖口」——现在这条需求会真正触发款式转换段。
