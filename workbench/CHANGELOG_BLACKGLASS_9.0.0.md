## 1. 页面与交互

1. **确定视觉方案**：纯黑背景、深紫毛玻璃面板、灰白正文、银紫微光，保留明暗层次；不迁入原型里的三色对比和模拟场景开关。
2. **屏幕平面动效**：本地 Three.js 0.160.1 单画布，默认 64 个运动粒子，其他星点／雨丝关闭；包含边缘流光、点击反馈和显影反馈，不构建三维场景。支持暂停、减弱动态效果和 WebGL 不可用时的 CSS 降级。
3. **左右框对齐**：配置与结果主框可见边界同顶同底；款色区、结果画廊分别滚动，需求与生成按钮保持可见。小屏使用“配置／画布”切换。
4. **款式与颜色**：可折叠款式、多款式管理、当前款的色卡局部更新；全选、清空、添加和移除沿用实际款式库。
5. **生成设定**：突出模型、尺寸与质量入口，保留画面主体、自动比例、真实接口与模型价格、真实队列提示。
6. **素材上传**：先显示读取占位，再异步生成最大 160×200 小预览，保留原始 File 用于提交，移除后释放预览 URL。单张原图前端上限 20 MB；不再误把 skill 的成品打包上限当上传上限。
7. **诚实的即时反馈**：点击生成后立即显示“上传与规划／等待服务器确认”及预计数量；未取得任务 ID 前不冒充已开工，服务器返回后再按真实任务回填。创建失败恢复旧结果，提醒先查任务记录，绝不自动重发付费请求。
8. **成品显影**：生成中显示闪卡背面；图片成功解码后进行平面压缩／展开翻面。网格、灯箱、原图下载分别使用缩略图、预览图、后端原图接口，不用缩略图冒充原图下载。
9. **结果工具**：按完成／生成中／待处理／异常筛选，切换网格密度，保留选择、单张下载、批量导出、返工、重试、取消和任务日志。
10. **头像菜单**：飞书历史、我的用量、账号及退出收进头像菜单；管理入口独立，并按管理员权限显示。当前头像为本地 SVG 占位，不宣称 AI 生成成功。
11. **大图**：完整 `contain` 显示，保留上一张／下一张、关闭、原图下载及固定下载栏；提供键盘与焦点约束。

### 本轮修复的六项复核问题

| 问题 | 处理 |
|---|---|
| 分析仍在进行时用户手动生成，可能与 agent 自动提交重复开工 | 分析、直接生成、默认生成、返工和重试使用共享互斥；关闭抽屉不会绕过互斥；SSE 中间 prompt／done 帧不会提前放开尚未关闭的连接 |
| 切换历史任务时旧卡片对应新 jobId | 切换加载期间旧结果 inert、显示加载提示、禁用动作；渲染目标匹配后解除；取消／重试等先捕获目标 ID；飞书补写回包也校验目标 |
| 返工模型列表乱序覆盖 | 每次加载递增请求序号并校验 provider；模型未读完时禁止分析和提交，不回退到主面板模型 |
| 重复 watch 或 A→B→A 留下多条轮询 | 每次 watch 使用 epoch 和 AbortController；成功、失败、定时器均校验当前身份，旧错误不能污染新任务状态 |
| 我的用量显示全员总额 | `/api/usage` 始终按当前认证账号过滤，所有汇总与 recent／accounts 同步过滤；管理员全员看板保持原行为；前端个人摘要单独读取个人接口 |
| 手填模型切接口后被默认模型覆盖 | 显式恢复 `__manual__`，按 provider 保存和恢复手填文本，仍校验异步模型请求身份 |

## 6. 启用、回退与限制

- 前端无构建步骤，直接由 FastAPI StaticFiles 提供；旧浏览器请 Ctrl+F5。原 `run.bat`／`python serve.py --open` 仍可启动。
- 本轮包含 Python 后端改动，仅刷新浏览器不足以加载账号过滤；服务端须在确认无运行中任务后重启。本次已加载新后端恢复正式 8787 服务。
- 回退前先备份当前工作树及 `data/`。恢复改造前 `index.html`、`app.js` 和所需的后端改动，递增缓存版本并重启；旧 `style.css`、`glass.css`、`aurora.css` 未删除。不要用 `git reset --hard` 覆盖并发修改，也不要清空数据或改密钥。首次迁移前的两份首页文件另有会话 scratch 备份，长期回退应自行纳入版本管理。
- 真实测试产物在隔离数据目录，不会出现在正式历史或正式账本。临时测试服务在交付时关闭；正式 8787 保留运行。
- 飞书功能与群通知入口及后端逻辑保留，**本轮没有实发飞书记录／群通知**。SSE 与返工提交竞态使用受控响应回归，未另行付费跑 DeepSeek 或返工图；未做新的百张真实并发压测。
- 当前为本地 SVG 头像。此前专用图像生成工具返回 `IMAGE_NOT_CONFIGURED`，没有偷偷换模型或调用其他接口制作头像。
- GT 710／内置预览环境可能出现调度抖动；没有“稳定 60 FPS”的承诺。性能策略是单画布、动态降级、懒加载、小缩略图与局部 DOM 更新；可手动暂停微光。
- Three.js 0.160.1 兼容包会输出 legacy-build 弃用提示，不等于运行错误；后续升级依赖应单独验证 WebGL 材质及像素结果。
