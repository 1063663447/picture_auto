# 9.1.1 · 原图／成品双来源与正反面构图修复

日期：2026-11-06。正式网页资源版本为 `9.1.1`。保留 9.1.0 的主备接口、固定计价、滚动动效、harness 分流和总耗时功能；本轮未修改 README、接口配置或历史成品。

## 问题与修复

用户原图是一张 800×800 的画布，同时含左侧正面、右侧背面；成品为 1254×1254 的白色卫衣单正面。旧改图对话只读取成品，返工任务也只复制成品作为输入，所以模型无法对照已丢失的背面。

1. **harness 实际接收两类图片**：原始上传图、当前待改成品。每张 image_url 前附中文角色、item/view、文件名和任务信息，避免将图片文件数当成服装视角数。单张文件内有正反面时必须看完整画布。在线预览长边上限由 900 提至 1200，原文件不改写。
2. **原图来源追溯**：新 `sources.py` 按任务、item 和 view 找回原始上传文件，兼容旧返工链与连续多轮返工。新返工在自己的 `originals/` 目录保留原图字节副本及精确 `source_task_map`；来源缺失或有歧义时提示，不把当前成品冒充原图，不猜取其他 item。
3. **返工模型同时拿当前图和原图**：输入顺序为当前成品、原始上传图；在接口容量内保留更多同 item 的原始视角。当前图负责已确认的颜色／版型／工艺；原图负责原始画布视角数、正反面身份、布局和各面独有图案。恢复背面时不恢复原图黑色，不把正面胸标复制到背面。
4. **普通生成和派生保留全部原图视角**：提示词明确保留原始画布里的所有衣服／正反／侧面、相对位置、比例和重叠，不能套用单面款式图的构图；原图只有单面时不凭空增加背面。款式效果图继续控制版型、颜色和工艺。基准／两阶段派生在容量允许时增加原始上传图作为第三张参考，原有前两张顺序保持。
5. **避免继承错误图片角色**：返工时重新绑定当前输入的角色，清理旧“IMAGE 2 是效果图”等不再适用的段落；发送前按实际附图数再次生成角色说明。用户明确要求修改的图案策略继续有效，禁人物规则仍优先。
6. **看图工具准确报告尺寸**：逐张标注测量值及是否低于 1200px，不再附无条件通用警告；1254px 成品明确标为 ≥1200px，800px 原图才有放大风险提示。看图结果本轮缓存，避免重复测量。
7. **真实附件与报告一致**：编码失败的文件只进错误说明，成功附图、标签与工具报告共用同一份列表，防止首张图失败后编号错位；超过 6 个附件时说明未附带的对照组／视角。本地降级分析明确没有视觉能力，不冒充读过图。
8. **多视角返工任务身份**：返工保留原 item/view/garment，并以完整父任务 ID 生成下一轮 ID，避免同 item 的正反视角或多款式返工覆盖。

## 文件

- `skillbridge/sources.py`：原图来源追溯、路径包含关系校验、旧返工链与本地副本读取。
- `skillbridge/harness_media.py`：原图／成品配对、附件容量、角色标签、逐文件尺寸和风险判断。
- `skillbridge/api.py`、`agent.py`：真实附图、角色与说明透传；附图列表与检查报告一致；构图对照要求及准确尺寸判断。
- `skillbridge/service.py`：返工复制原图、副本元数据、父任务映射及 view/garment 保留。
- `skillbridge/prompts.py`、`runner.py`、`refine.py`：正反面画布约束、负面约束、基准／返工原图参考、旧角色清理。
- `web/app.js`、`index.html`：改图说明改为原图／成品对照，缓存版本递增 9.1.1。
- `tools/check_rework_sources.py`、`check_composition_preservation.py`：来源、连续返工、附件、尺寸、构图和请求级回归。
- `tools/selftest.py`、`check_effect_ref.py`：更新为新角色／三参考契约，并增加原图字节身份检查；保留原有图像顺序、调用数、fidelity、版型和工艺检查。

## 启用与边界

- 已在确认正式任务全部结束后重载 Python 服务；首页资源版本为 9.1.1，旧浏览器 Ctrl+F5。临时隔离测试实例已关闭，正式 8787 保留运行。
- 旧的失败成品不会被自动覆盖或重跑。重新打开该成品的“改图”，会回溯原始上传图；可用“按原图恢复同画布正反面及各自图案，保持当前白色”继续返工。
- 一张拼图仍是一张输出任务，保留原来的多个视角，不拆成额外收费任务。独立上传的多个 view 继续保留各自任务身份。
- 若原始文件已删除、旧记录无法确定来源，或接口仅支持一张输入，会明确说明限制，不虚构原图或额外视角。参考图片不裁切、不重写。
- 本次真实对话与唯一一张生图均在隔离目录和账号中执行，飞书同步、通知关闭；没有向他人发消息，没有修改原任务、密钥或计价配置。README 保持本轮开始时内容。
- 模型输出仍需人工复查 logo 字形、印花尺寸和细节。此次样本验证恢复双面有效，不等于所有模型／原图都能保证完全一致。
